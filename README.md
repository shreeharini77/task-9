# Task 9 – Credit Card Fraud Detection

This project detects fraudulent credit card transactions using Random Forest.

## Dataset
Credit Card Fraud Detection Dataset from Kaggle.

## Models
- Logistic Regression
- Random Forest

## Metrics
Precision, Recall, F1-score

## Output
- Feature importance plot
- Saved Random Forest model (.pkl)
